BIRTHDAY WEBSITE — QUICK SETUP

1. Open index.html in a browser to preview the website.
2. Replace the four photo placeholders with your own photos if desired.
3. To add music, put an MP3 named song.mp3 in this folder and change the audio setup in index.html.
4. To publish it, upload the folder to any static website host.

This version is mobile-friendly and contains:
- Opening birthday screen
- Personal letter
- Photo gallery placeholders
- 20 reasons section
- Relationship timeline
- Final birthday message
- Floating hearts and scroll animations
